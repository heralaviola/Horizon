# Tools update profile

Use this profile for release notes, changelogs, and version updates from software tools,
libraries, runtimes, developer utilities, and infrastructure projects that the reader
actively uses or follows.

Prioritize concrete feature additions, breaking changes, compatibility changes,
performance improvements, security fixes, and other changes that affect how a tool is
used.

Do not use this profile for general technology news, long-form tutorials, opinion pieces,
routine social activity, or release announcements without substantive change details.
