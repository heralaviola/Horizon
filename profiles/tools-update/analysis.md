# Evaluation goal

Evaluate software tool updates for readers who want to know what changed and whether they
should pay attention or upgrade.

# Scoring rubric

- **9-10: Major release.** A major version, important new capability, breaking change,
  critical security fix, or substantial performance/compatibility improvement.
- **7-8: High value.** Several useful features, a meaningful workflow improvement, or a
  change likely to affect many users of the tool.
- **5-6: Useful update.** A concrete incremental feature, compatibility improvement, or
  meaningful bug fix worth knowing about.
- **3-4: Low priority.** Mostly maintenance, small fixes, documentation, dependency
  refreshes, or changes with limited user impact.
- **0-2: Noise.** No substantive change, duplicate content, unrelated material, or a
  release note that does not provide enough information to evaluate.

# Evaluation guidance

Score the update itself, not the popularity of the repository. Consider the clarity of the
release notes, user impact, backward compatibility, migration effort, security relevance,
and whether the change affects the tool's core workflow. Use three to five specific topic
tags.
